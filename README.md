# Анализ каталога Netflix на PostgreSQL
О проекте
Анализ каталога Netflix: 8807 тайтлов (фильмов и сериалов) с 1925 по 2021 год.
Цель — выявить тренды по странам, жанрам, годам и целевой аудитории.

Данные
- Источник: [Netflix Movies and TV Shows — Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- Объём: 8807 строк, 12 колонок
- Поля: show_id, type, title, director, cast, country, date_added, release_year, rating, duration, listed_in, description

Инструменты
- PostgreSQL 16
- pgAdmin 4

Что сделано
1. Загрузил CSV в PostgreSQL через `COPY`
2. Проверил качество данных (пропуски, диапазоны, уникальные значения)
3. Проанализировал структуру каталога через `GROUP BY`
4. Выявил топ-страны, топ-жанры, динамику по годам
5. Применил оконные функции (`RANK`) для анализа жанров по странам
   
Ключевые выводы
1. Фильмы доминируют над сериалами
Movies — 6131 (70%), TV Shows — 2676 (30%).

2. США — лидер, но Индия неожиданно на 2-м месте
США: 2818 тайтлов, Индия: 972, Великобритания: 419.
Индия обгоняет европейские рынки — это отражение стратегии Netflix
по инвестициям в Bollywood и азиатский рынок.

3. Международный контент — главный приоритет
Топ-1 и топ-4 жанры — International Movies (2752) и International TV Shows (1351).
Вместе это ~47% каталога. Netflix — глобальная платформа.

4. Контент ориентирован на взрослую аудиторию
61% контента — рейтинги TV-MA и TV-14 (для 14+).
Детского контента (TV-Y, TV-G, G) — менее 7%.

5. Пропуски в данных
В колонке `director` — 30% пропусков (2634 из 8807).
Остальные ключевые поля (страна, дата) заполнены на 90%+.

6. Разные страны — разные жанры (оконные функции)
С помощью `RANK() OVER (PARTITION BY country)` выяснил топ-3 жанра для каждой страны.
В США популярны драмы и комедии, в Индии — международное кино, в Японии - аниме.
Это подтверждает стратегию Netflix: платформа адаптирует контент под рынок,
а не продвигает один и тот же контент везде.

Структура проекта
- `01_explore.sql` — разведка данных и базовый анализ: типы контента, рейтинги, топ-страны, топ-жанры (7 запросов)
- `02_analysis.sql` — продвинутый анализ: топ-3 жанра для каждой страны через оконную функцию `RANK`
-`results/` — 8 CSV с результатами всех запросов
- `results/netflix_dashboard.png` — скриншот дашборда Power BI
- `results/netflix_dashboard.pbix` — исходный файл дашборда
